# ✏️ h-pen

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue?logo=python)](https://www.python.org/)
[![PySide6](https://img.shields.io/badge/GUI-PySide6-green?logo=qt)](https://doc.qt.io/qtforpython/)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Status](https://img.shields.io/badge/Status-Alpha-orange)]()

A modern infinite canvas drawing application built with **Python + PySide6**.

h-pen is a lightweight digital notebook and drawing app with an infinite canvas, grid paper mode and a modern interface.

## ✨ Features

- ♾️ Infinite canvas
- 📐 Grid paper mode
- ✏️ Freehand drawing
- 🎨 Custom pen colors
- 📏 Adjustable brush size
- 🧽 Eraser tool
- 🔍 Canvas zoom
- 🌙 Modern dark interface
- 🖊️ Tablet support foundation

## 🚀 Installation

### Requirements

- Python 3.10+
- PySide6

Install dependencies:

```
pip install PySide6
```

Run h-pen:

```
python main.py
```
